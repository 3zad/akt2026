Koosta JFLAP-is lõplikud automaadid järgmistele keeltele.
Lahendused tuleb esitada Moodle'isse ning nende failinimed peavad olema yl1.jff, yl2.jff jne.

1. Sõnad üle tähestiku {a,b}, mis lõpevad tähega 'a'.
2. Sõnad üle tähestiku {a,b}, mis ei sisalda "ab".
3. Sõnad üle tähestiku {a,b}, mis sobituvad regulaaravaldisega "b?(ba)+".
4. Sõnad üle tähestiku {a,b}, mis lõpevad tähega 'a' **või** ei sisalda "ab".
   (Automaatide yl1 ja yl2 keelte ühend)
5. Sõnad üle tähestiku {a,b}, mis lõpevad tähega 'a' **ja** ei sisalda "ab".
   (Automaatide yl1 ja yl2 keelte ühisosa)
